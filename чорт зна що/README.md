# Синтетичний стенд: вибір мінімально достатнього маршруту передобробки

Порядок запуску (Python 3, numpy, opencv-python, scikit-learn):

1. `python3 train_det.py` — навчання детектора HOG + лінійний SVM лише на нормально експонованих кадрах → `svm.npy`.
2. `python3 collect.py train 100 1001 0` … `python3 collect.py train 100 1004 3` — навчальна вибірка (4×100 кадрів).
   `python3 collect.py test 100 2001 0`, `python3 collect.py test 75 2002 1`, `python3 collect.py test 75 2003 2` — тестова (250 кадрів).
3. `python3 analyze.py 0.05` — еталонні маршрути, навчання селекторів, порівняння стратегій, бутстреп 95 % ДІ.
   `python3 analyze.py <eps> quick` — лише порівняння з критерієм максимальної точності.
4. `python3 ci_s4.py` — S4(b): поріг аналога за рівної точності та 95 % ДІ з повторним добором порогу в кожній бутстреп-вибірці.
5. `python3 extra_checks.py` — модельний сценарій зі швидшим детектором.

Збережені артефакти: `svm.npy` — ваги детектора, використані в експерименті (LinearSVC навчено без фіксації random_state);
`data/train_*.pkl`, `data/test_*.pkl` — зібрані дані (вектори Контуру 1, детекції та виміряний час для кожного маршруту).
Для аналізу без повторного збору скопіюйте файли з `data/` у робочу теку й запускайте кроки 3–5.

Допуск достатності: маршрут достатній, якщо його покадрова AP@0.5 ≥ max_R AP − eps.
Нічиї в критерії максимальної точності розв'язуються на користь дешевшого маршруту (консервативно щодо аналога).
Час — виміряний на кожному кадрі для кожного етапу; частота кадрів = 1 / середній час кадру.
Результати характеризують метод на синтетичних даних із модельним детектором.
