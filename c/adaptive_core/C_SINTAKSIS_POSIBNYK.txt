ПОСІБНИК З СИНТАКСИСУ C (коротко, для розбору adaptive_core)
============================================================

Важливо: у C коментарі пишуть через // або /* ... */, а НЕ через #.
Знак # у C — це препроцесор (#include, #define, #ifndef), не коментар.


1. ФАЙЛИ
--------
.h  — заголовок: типи, константи, оголошення функцій (що існує).
.c  — реалізація: тіла функцій (як саме працює).
main() — звідси стартує програма.


2. ПРЕПРОЦЕСОР (#)
-----------------
#include <stdio.h>     підключити стандартну бібліотеку
#include "adaptive.h"  підключити наш файл

#define AD_BUDGET 5    зробити ім’я-заміну: скрізь AD_BUDGET -> 5
#ifndef X ... #endif   «якщо X ще не визначено»
#ifdef X ... #endif    «якщо X уже визначено»


3. ТИПИ ДАНИХ
-------------
int       ціле (зі знаком)
float     дробове
double    дробове точніше
char      один символ / маленький байт
uint8_t   беззнаковий байт 0..255     (з stdint.h)
uint16_t  0..65535
uint32_t  велике беззнакове ціле
void      «нічого» (немає значення)


4. ЗМІННІ
---------
int x = 10;           створити x і покласти 10
x = x + 1;            збільшити
x += 1;               те саме коротше
const int n = 5;      константа (змінити не можна)
static uint8_t buf[]; живе весь час роботи програми (не на стеку виклику)


5. МАСИВИ
---------
int a[3] = {1, 2, 3};
a[0]      перший елемент (індексація з нуля)
a[2]      третій елемент


6. ВКАЗІВНИКИ (*)
-----------------
Вказівник — адреса в пам’яті.

int value = 7;
int* p = &value;   // p зберігає АДРЕСУ value
*p = 9;            // записати 9 туди, куди вказує p (тобто в value)

У наших структурах:
  frame->width     те саме, що (*frame).width
  тобто «візьми структуру за вказівником і поле width»


7. STRUCT / ENUM
----------------
enum AdRoute { NONE=0, DENOISE=1, ... };  іменовані числа
struct AdFrame { uint8_t* data; ... };    кілька полів разом
AdFrame f;                                змінна типу структури
f.width = 160;                            доступ через крапку
AdFrame* pf = &f;                         вказівник на структуру
pf->width = 160;                          доступ через стрілку


8. ФУНКЦІЇ
----------
тип_результату ім’я(аргументи) {
  ...
  return значення;
}

void foo(void)      нічого не повертає, аргументів немає
int bar(int x)      приймає int, повертає int
static float helper(...)  видно тільки всередині цього .c файлу


9. if / else
------------
if (умова) {
  ...
} else if (інша) {
  ...
} else {
  ...
}

Порівняння:
  == рівне
  != не рівне
  < > <= >=
  && і
  || або
  ! ні


10. ЦИКЛИ
---------
for (i = 0; i < n; i += 1) { ... }   повторити n разів
while (умова) { ... }                поки умова істинна

break     вийти з циклу
continue  наступна ітерація


11. ПРИВЕДЕННЯ ТИПІВ (cast)
--------------------------
(float)n          трактувати n як float
(uint8_t)v        обрізати/перетворити до байта
(AdRoute)r        сказати компілятору: r — це AdRoute


12. ПАМ’ЯТЬ (дуже коротко)
-------------------------
Стек: локальні змінні функції (швидко з’являються/зникають).
Статика/глобали: живуть увесь час (наші g_line_prev).
malloc: динамічна купа (у нашому ядрі НЕ використовуємо — економія й контроль).


13. ТИПОВИЙ СКЕЛЕТ ПРОГРАМИ
---------------------------
#include <stdio.h>

int main(void) {
  printf("hello\n");
  return 0;
}


14. ЯК ЧИТАТИ НАШ АЛГОРИТМ ОДНИМ РЕЧЕННЯМ
-----------------------------------------
ad_decide():
  заміряти кадр (noise/blur/dark)
  -> порахувати score ŝ
  -> якщо ŝ вже високий: NONE
  -> інакше порахувати U для кожного маршруту
  -> взяти маршрут з найбільшою U
ad_apply_inplace():
  виконати вибраний маршрут прямо в буфері кадру


15. МІНІ-СЛОВНИК
----------------
prototype   оголошення функції без тіла
header      .h файл
compile     перетворити .c -> машинний код
link        зібрати об’єктні файли в програму
undefined behavior  небезпечна помилка (наприклад писати в NULL)


Якщо щось у коді все одно неясно — кидай конкретний рядок/файл, розберемо його окремо.
